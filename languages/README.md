# Ask language packs

Language packs map human-language spellings to canonical Ask frontend tokens. The lexer loads `.asklang` files recursively, so supported keywords can be mixed in one `.as` source file.

Current frontend token vocabulary: PRINT, VAR, TRUE, FALSE, NONE, IF, ELSE, WHILE, RETURN.

The initial packs cover English, Tamil, Telugu, Hindi, Kannada, Malayalam, Mandarin Chinese, and Japanese.
